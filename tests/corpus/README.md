# Test corpus

Every file here is made by the TBCAD project (MIT licensed). There are no customer drawings in
the repository; real-world samples that the owner provides stay in a private location.

- `synthetic/lexer/` - tokenizer test files (see its README).
- `reader/` - DXF files for the importer with an `<name>.expected.json` each (W3-2). Generated by
  `gen/gen_corpus.py` (ezdxf, MIT, is used by the script and in CI only, never linked).
  `gen/check_corpus_ezdxf.py` cross-checks the expected counts against ezdxf.
  `gen/gen_big_dxf.py` writes a 50 MB file for timing `tbcad-convert`.
- `roundtrip/` - reserved for the DXF exporter tests (W4-6).

Regenerating rewrites the files (ezdxf puts fresh timestamps and GUIDs in the headers), so only
regenerate when the corpus itself changes.
